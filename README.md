# Smart Inventory Management System

A full-stack Inventory Management System built using React, Node.js, Express.js, and MongoDB.

## Features

- Add Products
- Update Products
- Delete Products
- Search Products
- Filter by Category
- Inventory Dashboard
- Inventory Analytics Charts
- Low Stock Alerts
- Export Inventory to Excel
- Dark / Light Mode
- Responsive UI

## Key Highlights

- Full CRUD Operations (Create, Read, Update, Delete)
- Dynamic Inventory Dashboard
- Real-time Inventory Statistics
- Category-wise Analytics Charts
- Excel Export Functionality
- Search and Filter System
- Low Stock Monitoring
- Dark / Light Theme Toggle
- Responsive Modern UI

## Tech Stack

### Frontend
- React.js
- CSS3
- Recharts
- XLSX

### Backend
- Node.js
- Express.js

- MongoDB

### Backend

```bash

npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
