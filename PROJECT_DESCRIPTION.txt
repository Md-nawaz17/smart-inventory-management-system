STOCKPILOT
=========

StockPilot is a full-stack inventory management application for small teams and
portfolio demonstration. It gives each authenticated user a private workspace
to manage stock, log product movement, identify items that need attention, and
review inventory trends.

Repository: https://github.com/Md-nawaz17/smart-inventory-management-system
Live application: https://stockpilot-im-app.vercel.app
Live API: https://stockpilot-api-app.vercel.app


CORE CAPABILITIES
-----------------
- Register and sign in with JWT authentication.
- Manage products with name, category, supplier, quantity, price, and a
  configurable reorder point.
- Record stock-in and stock-out transactions without allowing stock to fall
  below zero.
- Search, filter, paginate, and export products to an XLSX workbook.
- View inventory value, category totals, low-stock alerts, and 30-day movement
  charts.
- Use a responsive dashboard with light and dark themes.
- Receive feedback through toast messages, a product-delete confirmation, and
  a notification panel for low-stock and zero-stock items.


TECHNOLOGY
----------
Frontend: React, Vite, Tailwind CSS, React Router, Axios, Recharts, Lucide
React, and SheetJS/xlsx.

Backend: Node.js, Express, MongoDB, Mongoose, JWT, bcryptjs, Helmet, and
express-rate-limit.

LOCAL DEVELOPMENT
-----------------
1. In backend/, install dependencies and create .env with MONGO_URI and
   JWT_SECRET. Run: npm run dev
2. In frontend/, install dependencies and set:
   VITE_API_URL=http://localhost:5000/api
   Run: npm run dev
3. Open http://localhost:5173


DEPLOYMENT
----------
Production runs on Vercel:
- Frontend: https://stockpilot-im-app.vercel.app
- API: https://stockpilot-api-app.vercel.app

Deploy the API through Vercel with backend/ as the project root. Set MONGO_URI,
JWT_SECRET, JWT_EXPIRES_IN, and CLIENT_URL.

Deploy the frontend through Vercel with frontend/ as the root directory and set
VITE_API_URL to https://stockpilot-api-app.vercel.app/api.

The backend must be redeployed after CLIENT_URL is updated with the final
Vercel domain.
